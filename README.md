# TaskFlow

> Modern, animated task management application built with pure HTML, CSS and JavaScript.

TaskFlow is a frontend-focused task management application designed as a portfolio project. It combines a dark glassmorphism interface with interactive animations and browser-based persistence using Local Storage.

## ✨ Features

- Create, complete and delete tasks
- Search tasks instantly
- Filter tasks by status
- Dashboard statistics with animated counters
- Persistent data with Local Storage
- Animated navigation and page transitions
- Hover effects and 3D mouse-following card tilt
- Magnetic button interactions
- Animated background elements
- Toast notifications
- Responsive desktop, tablet and mobile layout
- Reduced-motion accessibility support

## 🛠️ Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- Local Storage API
- CSS Animations & Transitions
- Responsive Design
